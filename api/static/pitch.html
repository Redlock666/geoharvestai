How It Works

Four stages. One recommendation.
Under three seconds.

A single API call — with just latitude, longitude, and season — triggers a four-stage AI pipeline that fuses GIS, weather, ML forecasting, and LLM reasoning.

1

Resolve the field's physical fingerprint

Coordinates are mapped to an H3 hex cell (~5 km²). PostGIS returns soil nitrogen, phosphorus, potassium, pH, texture class, elevation, slope, and Köppen-Geiger climate zone — all pre-indexed for sub-millisecond lookup.

SoilGrids v2 (ISRIC) SRTM 30m DEM Beck 2018 Climate Map ICAR 15-Zone Classification
2

Fetch real-time weather & crop health

7-day rainfall, temperature range, and humidity are served from a TimescaleDB cache refreshed nightly via ERA5. NDVI — the satellite measure of crop canopy health — is updated every 5 days via Sentinel-2.

ERA5-Land (Copernicus) Open-Meteo (real-time) Sentinel-2 NDVI MODIS MOD13A2 (history)
3

Run the ML ensemble

A SARIMAX model captures seasonal crop cycles and is used when data history is limited. An LSTM network learns non-linear weather-yield relationships from 15 years of district-level data. Both models are ensembled, producing a confidence score and yield estimate (kg/ha) for each crop.

LSTM (PyTorch) SARIMAX (statsmodels) APY Portal 1966–2026 ICRISAT VDSA
4

Generate agronomic reasoning

OpenAI's o3 reasoning model explains why each top crop was recommended — covering soil fit, weather risk, market timing, and sowing advice — in plain language a field agent or farmer can act on immediately.

OpenAI o3 LangGraph orchestration LangChain LCEL
